# Indicative 8-week implementation roadmap

| Week | Deliverable | Acceptance evidence |
|---|---|---|
| 1 | Requirements, threat model, schemas, repository CI | Public docs, issue tracker, lint |
| 2 | SDK intent validation and directory adapter interface | Unit tests and example |
| 3 | Escrow contract and comprehensive tests | Test report, fuzz/invariant tests |
| 4 | Celo testnet deployment and two-agent demo | Testnet contract and recording |
| 5 | ERC-8004 compatibility and Self Agent ID integration | Verifiable identity references |
| 6 | Security review and fixes | Review report and resolved findings |
| 7 | Mainnet deployment only after review/readiness | Verified contracts and deployment evidence |
| 8 | Pilot integrations and real usage | Independent integrations and transaction hashes |

This is a planning estimate, not a promise. Mainnet deployment must not be rushed to meet a grant deadline.
